# PERN Todo App

A full-stack Todo application built using the PERN stack (PostgreSQL, Express, React, Node.js).  
The app allows users to create, view, update, and delete todos with a REST API backend.

---

## 🚀 Tech Stack

- Frontend: React.js + Bootstrap
- Backend: Node.js + Express (REST API)
- Database: PostgreSQL
- API Testing: Postman

---

## 📌 Features

- Add new todos
- View all todos
- Edit todos using a modal
- Delete todos
- Data stored in PostgreSQL
